## 🎯 Project Overview

Managing student academic records, personal information, courses, and examination performance manually can be time-consuming and difficult to maintain.

The **Student Management System** provides a centralized web-based platform for managing student information efficiently.

The system allows users to:

1. Add and manage student records.
2. Search and filter students.
3. View detailed student information.
4. Edit and delete student records.
5. Record subject-wise examination marks.
6. Automatically calculate total marks and percentage.
7. Calculate letter grades.
8. View academic results.
9. View important statistics through a dashboard.

The application runs locally through the command line and uses **SQLite3** as its database, so no external database server is required.

## 🚀 Key Features

### 1. Dashboard

The dashboard provides an overview of the student database.

It displays:

* Total number of students
* Male and female student counts
* Number of courses
* Recent student registrations
* Course-wise student information
* Quick navigation options

---

### 2. Student Registration

Users can add new students through a registration form.

The form includes:

* Student Name
* Roll Number
* Email
* Phone Number
* Gender
* Date of Birth
* Course
* Department
* Semester
* Address

The system validates the entered information before storing it in the database.

---

### 3. Student Directory

The Student Directory displays all registered students in a structured table.

Users can:

* View student records
* Search students
* Filter students
* View student details
* Edit student information
* Delete student records

---

### 4. Search and Filter

Students can be searched using:

* Student Name
* Roll Number

Records can also be filtered according to:

* Course
* Semester
