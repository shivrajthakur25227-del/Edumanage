Quick Launch Guide

Run directly on your local terminal using standard Python commands:

# 1. Create Virtual Environment
python -m venv venv

# 2. Activate Environment
# Windows: venv\Scripts\activate
# Mac/Linux: source venv/bin/activate

# 3. Install Dependencies
pip install -r requirements.txt

# 4. Start Application
python app.py

Database Architecture

  • students: demographic records, unique roll numbers, and contact info.
  • marks: subject scores with foreign key student_id referencing students table.
  • Security: Parameterized queries protect completely against SQL injections.
